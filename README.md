# [Episódio Zero](https://episodio-zero.rf.gd)

<p>Um lugar maneiro pra organizar seus animes! Explore as funcionalidades e comece a organizar seus animes agora mesmo!
</p>
<h2>Funcionalidades</h2>
<ul>
    <li>Cadastre-se como Usuário (nome de usuário e senha)</li>
    <li>Adicione animes que está acompanhando à sua lista</li>
    <li>Crie sua lista de animes concluídos</li>
    <li>Remova animes das listas facilmente</li>
    <li>Adicione notas nos animes concluídos</li>
    <li>Avalie com até 5 estrelas</li>
    <li>Mais funcionalidades em breve...</li>
</ul>
<h2>Tecnologias e Bibliotecas Utilizadas</h2>
<ul>
    <li><strong>Linguagens</strong>: <ul>
            <li>PHP</li>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>
    <li><strong>Bibliotecas/Frameworks</strong>: <ul>
            <li>jQuery (manipulação de elementos e requisições dinâmicas)</li>
        </ul>
    </li>
    <li><strong>APIs</strong>: <ul>
            <li>Google Custom Search API (busca automática pelas capas de animes)</li>
        </ul>
    </li>
</ul>
<h2>Técnicas e Práticas</h2>
<ul>
    <li>Implementação do padrão MVC para organização do código, facilitando a manutenção e escalabilidade</li>
    <li>Configuração de <strong>autoload</strong> para carregamento automático de classes, tornando o código mais limpo
    </li>
    <li>Design <strong>responsivo</strong> para melhor experiência em dispositivos móveis, garantindo acessibilidade em
        qualquer tela</li>
</ul>
